# 🚀 Как опубликовать Cravt на GitHub Pages

## Шаг 1: Создайте аккаунт на GitHub
1. Перейдите на https://github.com
2. Нажмите "Sign up" и создайте бесплатный аккаунт
3. Подтвердите email

## Шаг 2: Создайте новый репозиторий
1. Нажмите кнопку "+" в правом верхнем углу
2. Выберите "New repository"
3. Название: `cravt-app` (или любое другое)
4. Описание: "Cravt - Short Video Platform"
5. Выберите "Public"
6. ✅ Поставьте галочку "Add a README file"
7. Нажмите "Create repository"

## Шаг 3: Загрузите HTML файл
1. В вашем репозитории нажмите "Add file" → "Upload files"
2. Перетащите файл `cravt-fixed.html`
3. **ВАЖНО**: Переименуйте файл в `index.html` (это обязательно для GitHub Pages!)
4. Нажмите "Commit changes"

## Шаг 4: Активируйте GitHub Pages
1. Перейдите в Settings (Настройки) репозитория
2. В левом меню найдите "Pages"
3. В разделе "Source" выберите:
   - Branch: `main`
   - Folder: `/ (root)`
4. Нажмите "Save"
5. Подождите 1-2 минуты

## Шаг 5: Получите ссылку на ваш сайт
После активации GitHub Pages покажет ссылку вида:
```
https://ваш-username.github.io/cravt-app/
```

**Готово! Ваш Cravt теперь доступен онлайн! 🎉**

## 📱 Альтернативные способы публикации

### Вариант 2: Netlify (еще проще!)
1. Зарегистрируйтесь на https://netlify.com
2. Нажмите "Add new site" → "Deploy manually"
3. Перетащите файл `cravt-fixed.html` (переименованный в `index.html`)
4. Получите ссылку типа: `https://random-name.netlify.app`

### Вариант 3: Vercel
1. Зарегистрируйтесь на https://vercel.com
2. Нажмите "Add New" → "Project"
3. Загрузите файл
4. Получите ссылку

## 🛠️ Дополнительная настройка

### Добавить свой домен (опционально):
1. Купите домен (например на https://namecheap.com)
2. В настройках GitHub Pages добавьте свой домен
3. Настройте DNS записи у регистратора домена

### Обновить сайт:
1. Внесите изменения в HTML файл
2. Загрузите обновленный `index.html` в репозиторий
3. Изменения появятся через 1-2 минуты

## 📞 Поддержка

Если возникли проблемы:
- Проверьте, что файл называется точно `index.html`
- Убедитесь, что репозиторий Public (публичный)
- Подождите 2-3 минуты после активации Pages
- Очистите кеш браузера (Ctrl+F5)
